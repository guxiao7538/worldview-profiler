# worldview-profiler · 三观画像师

> "未经审视的生活，不值得过。"苏格拉底这句话大意如此，出自《申辩篇》。
>
> 短视频每天塞给你一种主义，家里学校又各教一套。你哪边都信一点，又哪边都不全信。
>
> 这个 skill 就做一件事。陪你把这些说法一个个捞出来，看看它们分别是谁，最后收进一张你能看懂、能核对、能改的画像。

## 它解决什么

不是测你是什么人格，不教你怎么选工作、怎么过人生。那些是后续衍生出来的事。

它只解决一件事：**消解思想打架的混乱**。你隐约觉得哪边都信一点，但到底哪套说了算、哪两套在打架，自己说不清。聊完这一趟，你会知道你脑子里有哪几套说法，哪套说了算，哪两套还没分出胜负。

聊完你会拿到一份《世界观画像》。先说人话，再给哲学注脚。每个结论都标着是你的哪句话推出来的，说错了当场改。先看一段人物速写，再看判断。

**它不做什么**：不给人格标签（MBTI 只给倾向推断＋依据，供参考）、不做职业规划、不做心理治疗。默认也不给人生建议。画像告诉你混乱点在哪，顺着混乱可以去看看哪些人。你想聊选择和行动，得主动说，那部分只在收尾另起一段。

## 两种玩法，先选一种

| | 快速访谈 | 完整访谈 | 问卷调研（新增） |
|---|---|---|---|
| 时长 | 约 15-20 分钟 | 约 40-60 分钟（可分几次聊完） | 快速卷约 10 分钟，完整卷约 25-35 分钟（可分两次） |
| 问题 | 4 个核心问题 | 十来轮，九个维度全覆盖 | 快速卷 Q0 到 Q6，完整卷 Q0 到 Q10，一次填完交回 |
| 产出 | 速写版画像 | 完整画像 | 问卷版画像（注明卷种与补问轮数，置信上限低于访谈版） |
| 适合 | 先尝味道，看看这东西对不对胃口 | 真想把脑子里的乱捋清楚 | 自填，或拿去问别人，回来一次交结果 |

对 AI 说「三观画像」开始。开场它先讲一句引子、再抛第一个问题，你开口之后才问你选哪种玩法。说「发我问卷」直接进问卷模式，快速卷自填或代问都行，完整卷覆盖九维加实践取向。任何题都可以跳过，中断后说「继续」接着画。

触发词：梳理三观 / 三观画像 / 世界观画像 / 思想画像 / 我想弄清楚自己到底信什么 / 重测三观画像 / 发我问卷 / 问卷调研 / 回收问卷。

## 画像长什么样（节选示例，虚构数据）

```markdown
## 零、人物速写
大事上你拍板很快，家里事就往后拖 [R4]。
你说过，选工作时看的是自己想去哪，过年回家就听安排 [R6]。
自己选的那套管远路，别让家人失望的那套管回家那段。

## 一、一句话定位
你本质上信自己能选，也信不确定里能活下去。
做事信小步试错。一碰到为家人牺牲多少就卡住。
自由和责任这两股力量在你这儿没分出胜负 [R4][R6]。

## 三、你的混乱点在哪
"自己选"和"别让家人失望"这两股力量在打架，
前者在大事上说了算，后者在过年回家时说了算。
```

哲学定位、原话依据、可以去了解的人都在画像里，完整格式见 [SKILL.md §7](SKILL.md)。

## 它是怎么工作的

两层内置资料驱动，运行时不需要联网：

1. **[references/question-bank.md](references/question-bank.md)（问什么）**：九维问题库——每维先说"为什么问这题"，再给选项化主问题和追问；术语清零，全是生活场景。
2. **[references/genealogy-map.md](references/genealogy-map.md)（怎么归）**：哲学谱系地图——6 层立场 + 触发式"自由意志"层，28 流派签名表，收敛算法 R1-R9（含并列型形态识别 R4b），外加一份"人话翻译表"（每个流派一句话生活语言，画像里术语出现必须配解释）与"引语使用规则"（复述作品的前提与意象不需逐字核对；只有打引号署名的原话才要求措辞确定）。

设计依据：Schwartz 价值观环形结构、Yalom 四大存在主义终极关怀、Park 意义建构模型、Frankl 意义治疗、道德基础理论（MFT）、Zimbardo 时间观、个人认识论（Hofer & Pintrich）；对话引擎借鉴"人生设计师"类提示词并做了画像化改造。

## FAQ

**这是 MBTI 那类测试吗？**
不是。画像里有一节认知风格侧写，会给四字母推断＋每字母一句你的原话依据＋免责声明（非正式测量，仅供参考），证据不够就宁缺不凑。画像正文的倾向描述比四个字母准得多。

**画像会准吗？**
画像是"基于你的回答的最接近近似"，不是判决。所有结论附原话依据供你核对，可当场纠正，欢迎日后重测。想法会变，画像跟着变，这是特性。

**聊完能得到人生建议吗？**
默认不能。本职是厘清处境，不是给方案。画像告诉你混乱点在哪，顺着混乱可以去看看哪些人。聊的过程中，关于"你这两句在打架"这类认知层面的提醒会随时给；至于你该选哪个、该干什么，收尾只留一句邀请。你说一声，我们另起一段。你不说，就不展开。

**会影响我的情绪吗？**
涉及死亡、创伤、孤独的问题都有轻量替代版且随时可跳过；检出明显低落会立即绕行。这不是心理治疗工具，若对话中出现危机信号，技能会暂停画像并建议你和信任的真人或专业人士聊。

**数据隐私？**
无联网调用、无遥测；对话在本机进行，产出文件写在你指定的本地路径。
