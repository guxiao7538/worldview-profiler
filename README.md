# worldview-profiler · 三观画像师

> 通过多轮一问一答，把「你到底信什么」捞出来，钉上证据，收进一张可核对的画像。

一个面向 [Agent Skills](https://code.claude.com/docs/en/skills) 生态的对话式技能：AI 像访谈者一样逐轮提问，帮你梳理**世界观、人生观、价值观**，最终产出一份**可追溯的思想画像**——每个结论都标注是你的哪句原话，并收敛到最接近的哲学思想簇与代表人物，允许混合型结论（如「儒家底色 × 斯多葛实践 × 存在主义意义观」）。全程中文对话。

**它不是**人格测试（不给任何标签，包括 MBTI 四字母）、不做职业规划、不做心理治疗。

## 特性

- **九维画像**：三观三轴作骨架，补上四块三观覆盖不到的盲区——认识方式、有限性与命运、自我关系、他人观，另含道德直觉、时间取向。
- **哲学谱系收敛**：内置 6+1 层立场地图 × 28 个中西流派签名表，按多轮回答逐层置信度收敛；同类流派自动触发二判题拆分。全部内置、断网可用。
- **可追溯**：证据分级登记（强/中/弱 + ≤30 字原话摘录 + 轮次号），画像中每个定性句都带 `[R#]` 回指；矛盾回答标记为「内在张力」如实呈现，不强行归一。
- **MBTI 只作侧写**：四个认知风格问题织入既有维度的追问（占 10%-15%），结论用倾向语言，拒绝四字母标签与巴纳姆句式。
- **防敷衍设计**：主问题选项化、对立面/边界情境/言行校验等六种追问手法、歧义短语（「佛系」「躺平」）强制澄清。
- **安全阀**：敏感题有轻量替代版且可跳过；检出情绪低谷立即绕行；虚无主义信号触发共情模式与转介提示，不硬推进。
- **断点续传**：进度落盘，中断后说「继续」即从断点接着画；支持日后「重测」与上一份画像对比。

## 使用

对 AI 说以下任意一句即可触发：

> 帮我梳理三观 / 做个三观画像 / 我的人生观是什么 / 我想弄清楚自己到底信什么 / 重测三观画像

**流程与时长**（标准模式 10-12 轮，约 35-60 分钟，可分多次完成）：

| 阶段 | 内容 | 轮数 |
|---|---|---|
| S0 开场 | 预期管理 + 自由叙事（先聊后判） | 1 |
| S1 你与世界 | D1 世界图景、D2 认识方式 | 2 |
| S2 什么值得 | D6 价值优先级（附时间取向）、D7 道德直觉 | 2 |
| S3 怎么活 | D3 意义来源、D4 有限性与命运 | 2 |
| S4 我与我/我与他人 | D8 自我关系、D9 他人观 | 2 |
| S5 校验收敛 | 言行校验、张力澄清、二判题 | 1-2 |

赶时间说「快速模式」（15-20 分钟，四维速写版）；任何题可跳过（记为「开放」，不硬编）；中断后说「继续三观画像」断点续传。

**产出文件**（默认用户主目录，可现场指定）：

- `世界观画像-YYYY-MM-DD.md` —— 最终画像
- `世界观画像-YYYY-MM-DD-底稿.md` —— 证据档案（每轮原话摘录，画像中 `[R#]` 的出处）

## 它是怎么工作的

两层内置资料驱动，运行时不需要联网：

1. **[references/question-bank.md](references/question-bank.md)（问什么）**：九维问题库——每维的主问题（选项化）、追问词库、MBTI 织入点、常见套路回答破解。
2. **[references/genealogy-map.md](references/genealogy-map.md)（怎么归）**：哲学谱系地图——认识论/本体论/人性/价值/实践/意义 6 层 + 触发式「自由意志」层，28 流派签名表，收敛算法 R1-R9（证据分级、置信度更新、张力标记、混合型输出、防错与降级规则）。

设计依据（提问维度与问法有实证出处）：Schwartz 基本价值观环形结构、Yalom 四大存在主义终极关怀、Park 意义建构模型、Frankl 意义治疗、道德基础理论（MFT）、Zimbardo 时间观、个人认识论（Hofer & Pintrich）；MBTI 仅作认知风格参照（其信效度争议正是本技能拒绝人格标签的原因）。对话引擎的轮转协议借鉴了「人生设计师」类提示词的实践并做了画像化改造。

## FAQ

**这是 MBTI 那类测试吗？**
不是。不给任何人格标签；MBTI 四维度只作为「认知风格侧写」轻量融入（约 10-15%），因为标签式测量重测翻转率高，而本技能追求每个结论可回指你的原话。

**画像会准吗？**
画像是「基于你的回答的最接近近似」，不是判决。所有结论附原话依据供你核对，可当场纠正，欢迎日后重测——三观会变，画像跟着变，这是特性。

**会影响我的情绪吗？**
涉及死亡、创伤、孤独的问题都有轻量替代版且随时可跳过；检出明显低落会立即绕行。这不是心理治疗工具，若对话中出现危机信号，技能会暂停画像并建议你和信任的真人或专业人士聊。

**数据隐私？**
无联网调用、无遥测；对话在本机进行，产出文件写在你指定的本地路径。
